# Governance

AnyFile Convert is a founder-led, open-source project. 

## Maintainers
The project is maintained by its original founders. They hold final say over architectural decisions, license changes, and what features are included in the core product.

## Decision Making
We believe in a "Vertical Slices" approach. We merge code that solves a specific user problem well, rather than generic abstractions. 

If you want to propose a major architectural change or add a completely new category of tool, please open an Issue to discuss it *before* writing code. For simple new tools (like a new image format converter), you can jump straight to a PR.

## Code of Conduct
All participants in this project must adhere to our [Code of Conduct](CODE_OF_CONDUCT.md).
