# Support

If you need help with AnyFile Convert, please use the following resources:

1. **Read the Documentation**: Check the README.md and other docs.
2. **Search Issues**: Check if someone has already encountered your problem in the [issue tracker](https://github.com/anyfile-convert/anyfile-convert/issues).
3. **Open an Issue**: If you believe you have found a bug, please open an issue using the Bug Report template.

Please note that AnyFile Convert is maintained by volunteers in their free time. We do not provide commercial support or SLAs.

## Known Limitations (V0.1)
- **Windows 11 Context Menu**: On Windows 11, the "AnyFile Convert" option appears under "Show more options". This is a known OS constraint that we plan to address in a future release (V0.2).
- **Malformed PDFs**: The internal PDF engine may struggle with heavily malformed or password-protected PDFs.
- **FFmpeg Requirement**: Video operations require FFmpeg to be installed on your system.
